# Smart Election Assistant

## Overview

Smart Election Assistant is a web-based application that helps users understand the election process, check their voting eligibility, and receive step-by-step guidance in a simple and structured manner.

---

## Features

* Eligibility check based on age
* Location-based election guidance
* Aadhaar verification (simulated)
* AI assistant with fallback error handling
* Clean and responsive user interface

---

## Tech Stack

* React (Vite)
* Tailwind CSS
* Google GenAI
* Netlify

---


## GitHub Repository

https://github.com/VioletCoode/smart-election-assistant

---

## Approach

The application follows a guided flow:
User inputs age → eligibility check → location input → confirmation → Aadhaar verification (simulated) → voting guidance.

---

## Note

The AI assistant includes fallback handling to ensure the application remains functional if the API is unavailable.
